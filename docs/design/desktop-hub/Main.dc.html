First run
Which machine is this?
Same app either way. The only question is whether this is the machine that stays on.
The one that stays on
A Mac on the desk, a Mini in the closet, a NAS. It becomes your hub: the one address your phone and every other machine talk to. Starts at login, restarts if it stops.
Set this machine up
Installs the hub, the node and tmux here. No account, no cloud.
Just connecting
You already have a hub somewhere else. Open its terminals from this machine, the way the phone does.
Connect to a hub
Paste the link the hub printed, or sign in.
You can change this later in Settings.
