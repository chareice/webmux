# Design plans

Dated design specs and their follow-up reports, kept as a record of what was
decided when.

They are **not** maintained. Everything written before 2026-08-31 uses the
names the project had at the time — `webmux`, `webmux-node`, `tc-hub`,
`tc-cli`, `WEBMUX_*`, `wmx_`, `~/.config/webmux/`. Commands in those files will
not run as written. `docs/facts.md` has the current names, and the mapping is
at the bottom of it.
